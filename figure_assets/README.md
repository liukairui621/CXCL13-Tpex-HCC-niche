# Figure layout assets

The four PNG files in this directory are the version-controlled panel exports used to reproduce the exact final layout of `Fig1.tif`. They preserve the manually approved panel geometry and typography without requiring the Photoshop working file.

The scientific content underlying these exports is generated by `scripts/07_figure1_single_cell.R`. Numerical values used to audit the marker dot plot are provided in `processed_data/Q1_dotplot_summary.csv`; per-cell UMAP coordinates and marker values are provided in `processed_data/GSE149614_TNK_cell_values.csv.gz`.

These assets are lossless PNG files. They are not raw data and are used only by `scripts/17_build_submission_layouts.py` for final figure composition.
